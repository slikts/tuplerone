### `ValueObject(object, filter?)`

Creates a deeply frozen object with value semantics. Two objects with the same structure produce the same reference:

```ts twoslash
import { ValueObject } from 'tuplerone';

ValueObject({ a: 1, b: { c: 2 } }) === ValueObject({ a: 1, b: { c: 2 } }); // → true
```

The passed objects are deeply frozen with `Object.freeze()`, and the return type is `DeepReadonly<A>`.

### Deep value semantics

Nested objects are also converted to value objects, so sub-objects maintain value semantics:

```ts twoslash
import { ValueObject } from 'tuplerone';
// ---cut---
const { a } = ValueObject({ a: { b: 1 } });
a === ValueObject({ b: 1 }); // → true
```

### Filtering keys

Pass a filter function to ignore certain entries:

```ts twoslash
import { ValueObject } from 'tuplerone';
// ---cut---
const filter = ([key]: [string, any]) => !key.startsWith('_');

ValueObject({ a: 1, _meta: 'x' }, filter) === ValueObject({ a: 1, _meta: 'y' }, filter); // → true
```

The filter is applied recursively to nested objects.

### How it works

`ValueObject` uses [`DeepCompositeSymbol`](/docs/usage/deep-composite-symbol) internally to compute a structural identity key for the object. If a value object with the same structure has already been created, the cached version is returned.

### Not a constructor

`ValueObject` is a plain function and cannot be called with `new`:

```ts twoslash
import { ValueObject } from 'tuplerone';
// ---cut---
// @errors: 7009
new ValueObject({}); // throws TypeError
```
