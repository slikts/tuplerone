---
title: DeepCompositeSymbol
description: Recursively create composite keys for objects based on their deep structure.
---

### `DeepCompositeSymbol(object, filter?)`

Creates a unique `symbol` that represents the deep structural identity of an object. Two objects with the same nested key-value structure produce the same symbol.

```ts
import { DeepCompositeSymbol } from 'tuplerone';

DeepCompositeSymbol({ a: 1, b: 2 }) === DeepCompositeSymbol({ a: 1, b: 2 }); // → true
typeof DeepCompositeSymbol({ a: 1 }) === 'symbol'; // → true
```

### Deep nesting

Nested objects and arrays are recursively resolved:

```ts
DeepCompositeSymbol({ a: { b: 1 } }) === DeepCompositeSymbol({ a: { b: 1 } }); // → true
DeepCompositeSymbol([1, [2, 3]]) === DeepCompositeSymbol([1, [2, 3]]); // → true
DeepCompositeSymbol({ a: 1, b: [2, 3] }) === DeepCompositeSymbol({ a: 1, b: [2, 3] }); // → true
```

### Filtering keys

Pass a filter function to ignore certain entries when computing identity:

```ts
const filter = ([key]: [string, any]) => !key.startsWith('_');

DeepCompositeSymbol({ a: 1, _internal: 2 }, filter)
  === DeepCompositeSymbol({ a: 1, _internal: 99 }, filter); // → true
```

The filter is applied recursively to nested objects as well.

### Relationship to ValueObject

[`ValueObject`](/docs/usage/value-object) uses `DeepCompositeSymbol` internally to compute object identity. If you only need a key for lookups (without creating a frozen value object), `DeepCompositeSymbol` is the more lightweight option.
