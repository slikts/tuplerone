## What is tuplerone?

In JavaScript, objects with the same contents are not equal by default:

```ts
[1, 2, 3] === [1, 2, 3]; // → false
```

tuplerone solves this by caching object creation so that the same arguments always produce the same reference. This gives you value semantics using plain `===`:

```ts twoslash
import { Tuple } from 'tuplerone';

Tuple(1, 2, 3) === Tuple(1, 2, 3); // → true
```

This is useful for memoization (e.g. React's `memo()`), using multiple values as composite `Map` keys, and anywhere you need structural equality without deep comparison.

## Quick start

```bash
npm install tuplerone
```

```ts twoslash
import { Tuple, CompositeSymbol, ValueObject } from 'tuplerone';

// Tuple: array-like value type
const a = { id: 1 };
const b = { id: 2 };
Tuple(a, b) === Tuple(a, b); // → true

// CompositeSymbol: lightweight key from multiple values
const key = CompositeSymbol(a, b);
typeof key === 'symbol'; // → true

// ValueObject: frozen object with value semantics
ValueObject({ x: 1 }) === ValueObject({ x: 1 }); // → true
```

## Features

- **Tiny**—under 1KB compressed, zero dependencies
- **Well-typed**—full TypeScript support (works from JavaScript too)
- **Well-tested**—full test coverage
- **Efficient**—WeakMap-based directed acyclic graph for O(1) lookups
- **Immutable**—all objects are frozen with `Object.freeze()`
- **Iterable**—tuples support `for-of`, spread, and destructuring
